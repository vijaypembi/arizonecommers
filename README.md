# React E-Commerce Frontend

A responsive and interactive e-commerce frontend built using **React.js**, **Tailwind CSS**, and **Context API**.

## Features

-   Product listing from FakeStore API
-   Shopping cart management with Context API
-   Responsive design with Tailwind CSS
-   Mobile-first approach
-   Interactive UI with animations
-   Cart persistence using localStorage
-   Order summary and checkout flow
-   Product search and filtering

### Prerequisites

-   Node.js (v16.x or higher)
-   npm (v8.x or higher)

## Live Demo

[View Demo](https://arizonecommers.netlify.app)

### Setup Instructions

1. **Clone the repository**

git clone 'https://github.com/vijaypembi/arizonecommers.git'
cd arizonecommers
npm install
npm start

### Assumptions

The API (fakestoreapi.com) does not support search/filter queries, so search is implemented client-side.

No user authentication is required.

The checkout button is non-functional as it's beyond frontend scope.

Product categories and filtering are hardcoded based on API limitations.
